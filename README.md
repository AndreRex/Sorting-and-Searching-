# Sorting & Searching Visualizer 🚀

Alat bantu interaktif untuk memahami cara kerja algoritma **Sorting** dan **Searching** secara visual, dirancang khusus untuk mahasiswa Computer Science (Ilmu Komputer) dan siapa saja yang sedang mempelajari algoritma dasar.

---

## ✨ Fitur Utama

### 📊 Algoritma Sorting
- **Bubble Sort** – Animasi perbandingan berpasangan dan penukaran elemen bersebelahan.
- **Selection Sort** – Visualisasi pencarian nilai minimum dan penempatannya di awal.
- **Quick Sort** – Pembagian array berbasis *pivot* dan partisi rekursif.
- **Merge Sort** – Teknik *divide and conquer* dengan penggabungan subarray terurut.

### 🔍 Algoritma Searching
- **Linear Search** – Pencarian sekuensial elemen demi elemen dari awal hingga akhir.
- **Binary Search** – Pencarian efisien pada data yang sudah terurut dengan membagi rentang pencarian menjadi dua.

### 🎨 Tampilan & Kontrol
- **Antarmuka Modern**: Bergaya Glassmorphism & Cyberpunk Neon dengan animasi halus.
- **Kecepatan & Ukuran Fleksibel**: Atur kecepatan animasi serta jumlah baris data secara dinamis.
- **Statistik Lengkap**: Melacak jumlah perbandingan (*comparisons*), penukaran (*swaps*), dan estimasi waktu eksekusi.
- **Analisis Kompleksitas**: Dilengkapi tabel Big O Notation (Time & Space Complexity) untuk setiap algoritma.

## 🛠️ Cara Menjalankan

Project ini dibuat murni menggunakan **HTML5, CSS3, dan Vanilla JavaScript**, sehingga tidak memerlukan instalasi dependensi apapun!

1. Clone repositori ini atau download ZIP-nya:
   ```bash
   git clone https://github.com/AndreRex/Sorting-and-Searching-.git
   ```
2. Buka folder project:
   ```bash
   cd Sorting-and-Searching-
   ```
3. Buka file `sorting dan searching.html` langsung di browser favorit Anda (Chrome, Edge, Firefox, dll.), atau gunakan extension **Live Server** di VS Code.
